[b][size=5]R3E Toolbox - Comprehensive Race Management Suite for RaceRoom[/size][/b]

Hello RaceRoom community! 👋

I'm excited to share a project I've been working on: [i]R3E Toolbox[/i] - a complete suite of tools designed to enhance your RaceRoom Racing Experience.

[b][size=4]What is R3E Toolbox?[/size][/b]

R3E Toolbox is a free, open-source desktop application (also available as a web app) that brings together multiple utilities to help you manage AI difficulty, fix race results, and create professional championship standings.

[b][url=https://github.com/deggesim/r3e-toolbox/releases/latest]⬇️ Download the latest version here[/url][/b] (Windows installer + portable version)

Or try the [b][url=https://r3e-toolbox.up.railway.app]web version[/url][/b] (works on any platform: Windows, macOS, Linux)

[b][size=4]Key Features[/size][/b]

[b]1. AI Management 🤖[/b]

Based on the excellent work from [url=https://github.com/pixeljetstream/r3e-adaptive-ai-primer]pixeljetstream's r3e-adaptive-ai-primer[/url], this tool helps you:

• Analyze your aiadaptation.xml file
• Use linear regression to predict lap times for unmeasured AI difficulty levels
• Validate fit quality and detect outliers
• Generate optimized AI settings for all your track/class combinations
• Remove synthetic data and re-fit with real race data

Perfect for league organizers or anyone who wants consistent AI competition across different tracks and classes.

[b]2. Fix Qualy Times ⏱️[/b]

RaceRoom sometimes saves race results with missing qualification times. This tool:

• Reads your qualification session file
• Matches drivers between quali and race sessions
• Patches the race results with correct qualification lap times
• Generates a corrected file ready for your records

[b]3. Build Results Database 🏆[/b]

Inspired by [url=https://github.com/pixeljetstream/r3e-open-championship]pixeljetstream's r3e-open-championship[/url], this feature:

• Analyzes multiple race result files from a folder
• Calculates championship standings with points, wins, podiums
• Generates beautiful HTML reports with official RaceRoom car and track icons
• Caches assets for offline use
• Creates standalone HTML files you can share with your league

[b]4. Results Database Viewer 📊[/b]

• Browse all your saved championships
• Search and filter by car, track, or championship name
• View detailed driver, team, and vehicle standings
• Export HTML reports or JSON data

[b]5. Settings & Configuration ⚙️[/b]

• Customize fitting parameters
• Configure validation thresholds
• Manage game data files
• Clear cached assets when needed

[b][size=4]Technical Highlights[/size][/b]

• [b]Cross-platform[/b]: Desktop app (Electron) or web browser
• [b]Modern tech stack[/b]: React + TypeScript with a clean, responsive UI
• [b]Local storage[/b]: All data stays on your machine (electron-store for desktop, localStorage for web)
• [b]No backend required[/b]: Completely self-contained application
• [b]Open source[/b]: MIT License - contributions welcome!

[b][size=4]Credits[/size][/b]

This project builds upon the fantastic work of [b]pixeljetstream[/b]:

• AI fitting algorithms from [url=https://github.com/pixeljetstream/r3e-adaptive-ai-primer]r3e-adaptive-ai-primer[/url]
• Championship standings logic from [url=https://github.com/pixeljetstream/r3e-open-championship]r3e-open-championship[/url]

[b][size=4]Getting Started[/size][/b]

1. [b]Download[/b] the [url=https://github.com/deggesim/r3e-toolbox/releases/latest]Windows installer[/url] or use the [url=https://r3e-toolbox.up.railway.app]web version[/url]
2. [b]Load your r3e-data.json[/b] file (the app can auto-detect it from your RaceRoom installation)
3. [b]Choose your tool[/b] from the sidebar and start processing your race data!

Full documentation and user guide available in the [url=https://github.com/deggesim/r3e-toolbox]GitHub repository[/url].
